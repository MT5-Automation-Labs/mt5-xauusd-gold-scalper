# Enums

Shared enumerations. Include the file that matches the name, for example `Enums/OrderSide.mqh`.

| File | Used for |
| --- | --- |
| `OrderSide.mqh` | Buy and sell |
| `PriceType.mqh` | Open, high, low, close, and derived prices |
| `CompareType.mqh` | Comparison operators used by iterators |
| `TwoStreamsConditionType.mqh` | How two series are compared (cross, above, below) |
| `StopLossType.mqh` | Stop expressed in pips, percent, price, or money |
| `TakeProfitType.mqh` | Target expressed the same way |
| `StopLimitType.mqh` | Stop and limit distance mode |
| `PositionSizeType.mqh` | Lot, risk, and balance sizing modes |
| `MartingaleLotSizingType.mqh` | Flat, multiplied, or added martingale lots |
| `MATypes.mqh` | Moving-average methods for stream factories |
| `DayOfWeek.mqh` | Weekday filters |

There is one definition of `MartingaleLotSizingType`. Include `Enums/MartingaleLotSizingType.mqh`.
